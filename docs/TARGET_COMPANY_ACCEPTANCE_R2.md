# Falcon Track · target_watch r2 验收

2026-11-20，macOS、Python 3.12、本机 r5 合并版。**部分通过**。L1 与 L3 实际取得了 5 家企业的公开索引；EDINET 凭据已从 macOS 钥匙串读取，官方主机的 robots 返回异常，业务接口未发送认证请求。不能判断 Key 的有效性，也不能确认 L2 实网可用。

## 改动与边界

名单支持 1–30 家。已把合规档位、名单、标题规则与增量水位分开。先按企业从所有索引发现标题，再按分数与全局/单企限额读取详情。L3 仅保留高分标题指针，L4 在任何网络操作前跳过。遇到 robots、认证或访问限制会记录失败，后续可重试。令牌、模型、付费搜索和定时任务没有接入本命令。生产 SQLite 和模型定义没有写入路径。

官网 HTML、PDF 真实页码、事件去重与人工字段沿用 r1。法定披露单日清单按本体及集团提交者代码共同过滤，ZIP 使用标准库处理，不将压缩包解压到文件系统；报表按章节、行号/页码和主体归属提取。完整结果、原件和 HTTP 账本保存在本机专用目录。公布的源码包不含网站原件、业务库或凭据。

## EDINET 凭据与实网阻塞

在不输出内容的前提下验证了系统凭据库可读。带 Key 的两轮均先访问金融厅主机的 robots，实际轨迹为 `GET /robots.txt → 302 → GET /notfound.html → 200 text/html`。返回的是「規定外操作が行われました」的操作提示，未取得有效规则，也没有 HTTP 404/410 的明确缺失响应。诊断与正式批次都保留。客户端记录 `robots_or_robots_unavailable:invalid_format`，停止这条来源，继续其他公司。两轮均无带 Key 的业务请求；没有查询到真实 API 清单或下载历史 CSV/PDF。这个结果不能用来判断服务端是否会接受 Key。

可以向金融厅核实注册 API 客户端适用的访问说明或 robots 地址。取得可核验说明后再进行独立的清单与历史报告验收。当前没有改用网页端或第三方代理。离线测试覆盖了金融厅可能用 HTTP 200 承载 JSON 错误状态的情况。[API 规格及错误码](https://disclosure2dl.edinet-fsa.go.jp/guide/static/disclosure/download/ESE140206.pdf) · [金融厅 EDINET 联系入口](https://www.fsa.go.jp/search/edinet-Information/information-00.html)

5 家本体代码分别为大塚 E00956、西川 E01112、芝浦 E01482、オーバル E02270、住友 E00819。大塚另查母公司 E21183；集团其他子公司的同国项目不直接归给大塚製薬。逐家公司保留了代码依据。オーバル官网要求深层链接事先联系，公开索引采用经产省同一法人号的记录。[金融厅代码对照](https://www.fsa.go.jp/search/20080304-1/01.htm) · [大塚控股报告](https://info.gbiz.go.jp/hojin/edinetDownload?docId=S100XUA7) · [オーバル条款](https://www.oval.co.jp/attention/) · [gBizINFO 法人记录](https://info.gbiz.go.jp/hojin/ichiran?hojinBango=4011101003936)

## 离线测试与压力回放

整个回归进程及子进程加载离线网络保护，阻止非回环域名解析与出站连接。合成测试使用临时目录，未调用真实金融厅服务或模型。真实业务命令烟测在独立进程中另行执行。

- 全量 pytest **592 passed + 31 subtests**，原 565 项基础上新增 27 项，保留 6 条既有依赖弃用警告。Django unittest **157/157** 通过。系统检查 0 问题，迁移检查输出 `No changes detected`。
- 回环 HTTP 服务模拟 30 家、300 条标题。第一轮仅请求 60 篇详情，相比逐条请求的 300 篇减少 **80%**；240 条低分均留审计。人工合成材料故意重复，得到 30 个独立事件，不用于估计营业效果。第二轮 30 个索引均发送两个条件请求头并返回 304，详情 0、重复新增 0。
- 同一轮注入 1 个 403 和 1 个超时，另 28 家正常取得 304；两类故障分开注入时，各自其余 29 家均完成。另测全局优先级、预算后续跑、配置降档后旧任务不可读取、日期水位和标题/原件隔离。
- L3 高分合成标题的详情请求和原件文件都为 0；L3 索引/robots 的详情跳转被拦截。L4 合成企业的自动请求为 0。测试覆盖三种法定文书、UTF-16 CSV ZIP、集团漏配与错误归属、PDF 页码、空清单、无 Key、401、429 和敏感查询脱敏。认证、限流或 robots 拦截后停止对应批次的 EDINET 读取。
- 用无效测试凭据检查 HTTP 日志、异常和输出文件；再用本机真实凭据在内存中检查四轮试点输出（含原始及 URL 编码形式），匹配 0 项。业务请求地址只在 TLS 发送边界拼入密钥，拒绝业务重定向。
- UTF-8 中日文字、含 CRLF 的二进制哈希、模拟 Windows 占用导致的临时替换失败与清理均通过。未在 Windows x64 实机运行，未验证真实 401/429 或真实 EDINET CSV 文本质量。
